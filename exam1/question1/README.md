# 第一题：10 名同学成绩降序排序

## 题目

输入 10 名同学的成绩：78、92、65、88、70、95、82、60、100、85，
把成绩按从高到低排序输出。

## 思路

1. 用一个长度为 10 的 `int` 数组存成绩，`for` 循环 + `cin` 从键盘读 10 个数；
2. 用 `<algorithm>` 里的 `sort` 排序，第三个参数传 `greater<int>()` 就变成从大到小；
3. 再 `for` 循环输出，用 `if (i != 9)` 控制最后一个数后面不加空格。

```cpp
sort(scores, scores + 10, greater<int>());//从大到小排
```

`sort` 默认是从小到大，想降序就得加 `greater<int>()`，还要 `#include <functional>`。

## 编译运行

```bash
g++ -std=c++17 main.cpp -o main
./main
# 输入：78 92 65 88 70 95 82 60 100 85
```

## 运行结果

```
请输入10名同学的成绩：成绩从高到低排序结果：
100 95 92 88 85 82 78 70 65 60
```

## 踩过的坑

- 一开始把成绩直接写死在数组里（`int scores[10] = {78, 92, ...}`），
  虽然结果是对的，但题目要求"输入"，老师会认为没完成，后来改成用 `cin` 读入；
- 只写 `sort(scores, scores + 10)` 是升序，要在第三个参数加上 `greater<int>()` 才是降序。
