# 第二题：Book 类的设计

## 题目

定义一个 `Book` 类：

- 私有成员：`title`（string）、`price`（float）、`stock`（int）
- 公有成员函数：构造函数、析构函数、`input()` 输入信息、`display()` 输出信息
- `main()` 里用 `new` 动态创建对象，用指针调用 `input()` 和 `display()`，最后 `delete`

## 思路

- 三个成员变量放在 `private` 里，外面不能直接改，只能通过 `input()` 和 `display()` 操作；
- 构造函数里给三个变量赋初值，析构函数里打印一句话，这样能看出对象什么时候被创建和销毁；
- `new` 出来的对象在堆上，用完必须 `delete`，否则就是内存泄漏。

## 编译运行

```bash
g++ -std=c++17 main.cpp -o main
./main
# 依次输入：C++入门 / 45.5 / 20
```

## 运行结果

```
请输入书名：请输入价格：请输入库存：书名：C++入门
价格：45.5
库存：20
Book 对象已销毁
```

（"Book 对象已销毁"是 `delete p;` 执行时析构函数打印的。）

## 踩过的坑

- 一开始在 `getline(cin, title)` 前面写了 `cin.ignore();`，
  结果输入 `C++入门` 之后书名变成 `++入门`，**第一个字被吃掉了**。
  原因是程序刚启动时输入缓冲区是空的，`ignore()` 会等你输入，然后把第一个字符丢掉。
  这里前面没有 `cin >>`，所以 `ignore()` 完全不需要，删掉就好了。
- 只有当 `input()` 之前用过 `cin >>`（比如先读了别的数字），缓冲区里残留一个回车时，
  才需要在 `getline` 前面 `cin.ignore()`。
