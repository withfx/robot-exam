# 第三题：统计英文字母、数字和其他字符

## 题目

输入一个字符串，统计其中英文字母、数字、其他字符的个数并分别输出。

## 思路

1. 用 `getline(cin, s)` 读一整行，这样字符串里的空格也能读进来
   （用 `cin >> s` 遇到空格就停了，会漏字符）；
2. `for` 循环遍历每个字符，用 `<cctype>` 里的两个函数判断：
   - `isalpha(c)` 是英文字母 → `letters++`
   - `isdigit(c)` 是数字 → `digits++`
   - 都不是 → `others++`
3. 最后输出三个数。

## 编译运行

```bash
g++ -std=c++17 main.cpp -o main
./main
# 输入：Hello, ROS2 2024!
```

## 运行结果

```
英文字母个数：8
数字个数：5
其他字符个数：4
```

（字母 H e l l o R O S 共 8 个；数字 2 2 0 2 4 共 5 个；逗号、两个空格、感叹号共 4 个。）

## 需要注意的地方

`isalpha` 和 `isdigit` 只能正确判断英文字母和 0~9。
一个汉字在 UTF-8 里占 3 个字节，程序是按字节循环的，所以输入中文时
一个汉字会被算成 3 个"其他字符"。测试的时候用英文 + 数字 + 符号就没问题。
